# School Management System

> ⚠️ **Note:** The GUI (`school.py`) was built with the help of generative AI.

A simple Python app to manage students and teachers — register them, record grades, look up or delete records. Data is saved locally in a JSON file.

## Files

- `school.py` — Main app, AI-generated Tkinter GUI (recommended)
- `main2.py` — Earlier command-line version(source-code)
- `main1.py` — Earliest command-line version(tutorial code)

## Run

```bash
python school.py
```

Requires Python 3.8+ (standard library only).

## Features

- Register students and teachers
- Add grades with auto-calculated average
- Look up, view all, and delete records
